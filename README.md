# planEa2qgis — v1.0.0

NCZ imar planlarını QGIS'e aktarır; e-Plan resmi gösterimiyle (tarama, renk, çizgi tipi, sembol) çizer. planEa ailesinin QGIS eklentisi.

- QGIS 4 (Qt6) ve QGIS 3.34+
- Saf Python; Netcad kurulumu gerekmez, Netcad dosyası içermez.

## Kurulum
`KUR.bat` çift tıkla, QGIS'i yeniden başlat. QGIS 4 profiline kurar.

## Kullanım
NCZ seç → Aktar. Kademe ve ölçek otomatik; istenirse elle seçilir. Çıktı NCZ ile aynı adlı `.gpkg`.
